DAWを操作しながら使う

補助拡張は未接続です。

  1. 配布ZIPの extension フォルダーを展開。
  2. Chrome / Edgeの拡張機能ページで「デベロッパーモード」をオンにし、「パッケージ化されていない拡張機能を読み込む」から選択。
  3. dt-cueを開き、拡張アイコンをクリックして、このタブを接続。
  4. 拡張の「キー設定」で各操作を割り当て、適用範囲を「グローバル」に設定。
  5. ここで一度再生し、DAWへ切り替え。
Ctrl + Shift + 7再生 / 一時停止Ctrl + Shift + 8選択単位で戻るCtrl + Shift + 9選択単位で進むCtrl + Shift + 0停止

ブラウザと対象タブを開いたまま使用してください。OS予約キーやDAWとの競合は別の組み合わせに変更。Webページ内のキー設定とグローバル設定は別です。メディアキー操作も対応環境で利用できます。
