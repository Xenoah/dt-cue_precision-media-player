## dt-cue v0.1.0 — 初回リリース

**微小な時間 *dt* を狙ってCUEする、動画・音声のリファレンスプレイヤー。**

名前は物理・微積分の *dt* と、DJの **CUE** を組み合わせています。GitHub Pagesで動作する静的Webアプリで、読み込んだファイルはブラウザ内だけで処理します。

### 主な機能

- 秒／フレーム／1ms単位のシーク、直接時刻入力、移動量設定。
- A–Bループ、0.5秒試聴、再生速度、音量・ミュート。
- AviUtl／After Effects／Premiereを参考にした3種類のウィンドウ配置。
- 18操作のキー割り当て変更・競合検出・保存。
- DJスタイルのLOW／MID／HIGH波形、全体波形、拡大・スクラブ。
- BPM推定、TAP、手動補正、参考ビート線。
- ステレオのオシロスコープ、FFT、ファイル全体のRMS・サンプルピーク。
- DAW操作中の再生・シーク用Chrome／Edge拡張。

### 検証と制約

- 自動テスト13件成功。ChromeでWAV／MP3／H.264・AAC MP4、1ms移動、30fps連続送り、ループ、キー変更・保存を確認。
- 動画のフレーム送りは指定FPSからの時刻計算です。VFRなどで厳密な1コマ精度は保証しません。
- BPMは推定値。長尺・大容量では全体解析を省略し、再生とライブ解析を利用します。
- PCMの再生速度を変えると音程も変化します。
- **実Windows＋DAWでのOSグローバルキー、実オーディオIFの出力・レイテンシーは未検証。** 非アクティブ操作には拡張の接続と「グローバル」設定が必要です。

詳しい手順は [README](https://github.com/Xenoah/dt-cue_precision-media-player/blob/v0.1.0/README.md)、確認範囲は [検証記録](https://github.com/Xenoah/dt-cue_precision-media-player/blob/v0.1.0/docs/VALIDATION.md) を参照。

### English

First release of **dt-cue**, a precision audio/video reference player named after the differential of time, *dt*, and the DJ **CUE** function.

Includes second/frame/1ms seeking, A–B loops, configurable shortcuts, three workspace presets, three-band waveforms, estimated BPM, stereo oscilloscopes, FFT and an optional Chromium extension for global commands. Media stays on the user's device. No external runtime dependencies or server APIs.

13 automated tests pass; core playback and navigation were checked in Chrome. Video steps are FPS-based time seeks, BPM remains an estimate, and real Windows/DAW global-shortcut operation has not yet been verified. See README for installation and limitations.
