## dt-cue v0.2.0 — DJ Pads & MIDI Learn

**10パッド、MIDI対応、鉛筆マークからの自由なキー／MIDIマッピングを追加。**

### 新機能

- **10個のパフォーマンスパッド**。初期設定はHOT CUE 1〜10、キーは1〜9／0。
- 空パッドで現在位置を記録し、再押下でその位置から再生。CUEの上書き・消去・波形マーカー。
- パッドごとに再生、シーク、試聴、ループ、音量、ビート移動などの操作を選択。
- **鉛筆→対象の操作をクリック→キーを登録／MIDI Learn**。一覧検索、重複検出、割り当ての移動、設定保存。
- **Web MIDI入力（Note / CC）**、機器・チャンネル別の学習、入力選択、抜き差し検出。
- MIDIフェーダー／ノブで音量と再生速度を操作。
- 1／2／4／8ビートループ、1ビート移動、速度±1%、速度リセット。
- 補助拡張にパッド1〜10のグローバルコマンドを追加。

[プレイヤーを開く](https://xenoah.github.io/dt-cue_precision-media-player/) · [操作方法](https://github.com/Xenoah/dt-cue_precision-media-player/blob/v0.2.0/README.md)

### ダウンロード

- `dt-cue-v0.2.0.zip`：本体、ソース、Windows起動スクリプト、補助拡張、説明、テスト、スクショ。
- `dt-cue-global-controls-v0.2.0.zip`：Chrome／Edge用補助拡張。
- `dt-cue-*.jpg`：3配置とキー／MIDI編集画面。
- `SHA256SUMS.txt`：SHA-256チェックサム。

v0.1.0の拡張を使っている場合は更新後にタブへ再接続してください。既存のキー設定は維持し、競合する新規パッドの初期キーは空欄にします。

### 検証と範囲

**22件の自動テスト成功。** Chromeでパッド記録／再生、数字キー、鉛筆編集、競合検出、Qへの変更、4ビートループ、再読み込み後の設定保持、モバイル幅を確認しました。

MIDIは入力専用。Note／絶対値CCに対応し、SysEx・MIDI出力・クロック同期・相対エンコーダーは含みません。MIDIアクセスは明示接続時に要求します。HOT CUE位置はファイル別・セッション内で保持し、ページ再読み込みで消去。キー・MIDI・パッドの操作設定は保存されます。

**実MIDI機器と実DAWでの配送・共有・遅延は未検証です。** MIDIの学習・接続・切断・権限拒否は模擬入力で検証しています。動画のフレーム精度、BPM推定、PCM速度変更時の音程変化についてはREADMEをご覧ください。

### English

Adds ten customizable performance pads, session HOT CUEs, pencil-based keyboard/MIDI mapping, MIDI Learn for Note/CC, beat loops and pitch-rate controls. The companion extension now exposes all ten pads as global commands. Existing keyboard bindings are preserved. Twenty-two automated tests pass; real MIDI hardware and DAW coexistence have not been tested. See README for supported MIDI messages and setup.
