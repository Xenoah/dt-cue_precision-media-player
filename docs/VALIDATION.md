## ChromeでのUI確認

クラウドのChromeでローカルHTTP配信したアプリを操作。

- デモWAV（48kHzステレオ）の読み込み、PCMデコード、128BPM表示、3バンド波形、ファイルピーク／RMS。
- 1ms移動で `00:00:00.001` を表示。
- PCM再生の進行とLIVE表示。
- 1〜2秒のA–B区間で継続ループし、後刻も区間内にあることを確認。
- 再生キーをSpaceからPへ変更し、Pで再生。ページ再読み込み後も設定が残ることを確認。初期設定への復帰も確認。
- 生成したH.264/AAC MP4（640×360、30fps、5秒）を読み込み、画面表示と連続送り `0.033 → 0.067 → 0.100秒` を確認。
- MP3（192kbps、8秒）のPCM読み込みと再生。
- 定常1kHz信号を含むMP4で、周期性不足時にBPMが未推定になることを確認。
- AviUtl／After Effects／Premiereで、パネル配置の切り替えを確認。
- 波形の4倍ズーム、FFT／オシロ切替時の設定コントロールを確認。
- 390px幅のiframe（スクロールバーを除く375px）で横方向のはみ出しがないこと、再生操作が画面下に常時表示されることを確認。

フレーム送り検証で発見した境界丸めによる重複フレーム送りを修正し、再確認済み。

## 検証していないこと

- Windowsでの拡張のインストールとOSグローバルキー登録、実際のDAWとの併用。
- スピーカー／オーディオIFからの実出力の聴感、レイテンシー実測、ループ境界のクリック音評価。
- Firefox／Safari／Edge、実スマートフォン、アクセシビリティ支援機器での実機試験。
- 長時間・大容量ファイルの負荷試験、特殊コーデック、多チャンネルの網羅試験、VFRの厳密なフレーム同定。
- 公開後のGitHub Actions実行結果はリポジトリのActions欄で確認できます。この記録のローカル検証は初回push前に実施。

拡張の模擬API検証は、OSによる実際のショートカット配送を保証するものではありません。
